# Street Kings · illustrated street deck

Ten original illustrations generated with the built-in image-generation tool for this project. No stock images, brand logos or remote image services are used. Optimized local WebP files (320 × 480) keep the whole art set under 600 KB. Card numbers, colors, icons and rules are rendered separately by CardView; baked-in art cannot change gameplay.

## Prompt set

Shared direction: original portrait 2:3, full-bleed illustration, detailed hand-painted urban comic / street-art screenprint, crisp ink contours, gouache colors, halftone and paper grain. Contemporary brick neighborhood, natural warm lighting, strong center silhouette and quiet outer corners for number overlays. Not futuristic; restrained neon. No text, numbers, borders, logos, watermarks or weapons.

Numbers and icons are high-contrast on solid paper-colored corners; illustrations are decorative and have empty alt text because the full playable card is already named for assistive technology.
